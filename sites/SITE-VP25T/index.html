游戏规则

基本玩法

三人游戏，一人为地主，两人为农民。抢地主阶段每人可叫1/2/3分或不叫，最高分者成为地主。

叫分规则

  • 每人可选择 1分 / 2分 / 3分 / 不叫
  • 必须比当前最高分高才能叫分
  • 3分为封顶，叫3分直接成为地主
  • 若都不叫，重新发牌

牌型大小

  • 单张：任意一张牌
  • 对子：两张相同点数的牌
  • 三张：三张相同点数的牌
  • 三带一 / 三带二：三张 + 单张 / 对子
  • 顺子：五张及以上连续点数的单牌
  • 连对：三对及以上连续点数的对子
  • 飞机：两组及以上连续点数的三张
  • 炸弹：四张相同点数的牌
  • 王炸：大王 + 小王（最大牌型）

计分规则

基础倍数 = 叫分分数。炸弹和王炸额外翻倍。

游戏设置

音效

当前版本暂未支持音效，后续更新将加入。

操作提示

  • 空格 — 不要
  • H — 提示
